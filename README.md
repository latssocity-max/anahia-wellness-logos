# ANAHIA Wellness - Concepts de Logos Interactifs

Page de presentation interactive des concepts de logos pour la marque **ANAHIA Wellness** (Soins & Hygiene).

## Fonctionnalites

- 4 concepts de logos vectoriels (SVG HD)
- Systeme de votes avec envoi par email
- Comparateur cote a cote
- 6 declinaisons de marque (carte, avatar, flacon, web, tampon, t-shirt)
- Navigation clavier (fleches gauche/droite)
- Compteur de vues par concept
- Telechargement SVG direct
- Affichage du code source SVG
